# Image Analysis for Master Thesis

Analysis code developed for the data analysis of my master's thesis project
**"Intracellular organization under mechanical confinement"**.

The repository contains two independent analysis workflows.

Each folder has its own README with requirements, input data format,
usage instructions, and a description of the outputs.

## Scope and adaptability

The code was written for data from confinement experiments, but the methods
are not specific to them. Both workflows can be adapted to other types of
experiments and conditions (e.g. different perturbations, cell types, or
imaging setups) by adjusting the input data and parameters.
